AXXA Agent · support

Support AXXA Agent.

AXXA Agent is free, with no account and no license key. It’s made by one developer at AXXA Lab™, in Brazil. If it saves you time, here is how to keep it going.

01Sponsor

Back it with money

A sponsorship pays for the hours that go into fixes, tests on real phones, and keeping up with six providers whose APIs keep changing.

Sponsor on GitHub

Monthly or one time. Sponsoring unlocks nothing in the plugin: it’s a thank-you, not a purchase.

02Without money

Or help without paying

  • Report what breaks

    A bug report with your platform, Obsidian version and the steps saves hours of guessing.

  • Star the repository

    People on GitHub judge whether a project is alive by its stars. One click.

  • Point people to it

    When someone asks about AI in Obsidian on a phone, send them the directory page.

  • Share a skill

    Skills are Markdown files. Post yours in Discussions so others can use it.

03What stays free

Nothing you use today goes behind a paywall

Every feature the plugin has today stays free. If paid options arrive, they will be new things built on top, never a lock on something that already worked. You pay your AI provider directly; the plugin takes no cut.
