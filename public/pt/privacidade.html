Política de privacidade

Esta política vale para este site e para o plugin AXXA Agent para Obsidian, os dois feitos pela AXXA Lab™. Em resumo: a gente não coleta os seus dados, a não ser que você patrocine o projeto. O site não usa cookies nem analytics, e o plugin não tem telemetria.

01Quem é o responsável

A AXXA Lab™, desenvolvedora do AXXA Agent, no Brasil, é a controladora dos dados deste site. Para qualquer dúvida de privacidade, escreva pra contato@axxalab.com.br. Esse endereço é o canal de privacidade; como agente de tratamento de pequeno porte, a AXXA Lab™ não indicou encarregado (Resolução CD/ANPD nº 2/2022, art. 11).

02Este site

  • É um site estático. Não tem formulário, conta, cookie, analytics nem anúncio.
  • Tudo o que ele mostra (texto, fontes, estilo, imagens) vem deste domínio. Ele não carrega fonte, script nem rastreador de terceiros.
  • O site fica hospedado no GitHub Pages, e a Cloudflare responde às consultas de DNS do domínio. Como qualquer servidor web, o GitHub recebe os dados técnicos que o navegador manda pra carregar uma página (como o seu endereço IP e o tipo de navegador) e pode guardar isso em registros, por segurança e pra entregar o site. Esse tratamento segue a Declaração de Privacidade do GitHub, e o DNS a Política de Privacidade da Cloudflare. A gente não usa esses registros. A base legal é o legítimo interesse em manter o site no ar e seguro (LGPD, art. 7º, IX).

03O plugin AXXA Agent

  • O plugin roda no seu aparelho, dentro do Obsidian. Não tem telemetria e não manda nada pra nós.
  • Quando você usa um provedor de IA (OpenAI, Anthropic, Google Gemini, OpenRouter, NVIDIA NIM, ElevenLabs ou o seu servidor Ollama), o seu aparelho manda as suas mensagens, os anexos e os trechos de notas que o plugin usa direto pra esse provedor, com a chave de API que você configurou. Cada provedor trata esses dados pelos próprios termos e política de privacidade.
  • Nas conversas de Vault Q&A e Agent, um interruptor por conversa nasce ligado: trechos das notas que combinam com a sua mensagem vão junto dela pro provedor do chat. No Chat ele nasce desligado.
  • As respostas aparecem como Markdown, então um link de imagem dentro de uma resposta é carregado de onde ele aponta, e esse servidor vê o seu endereço IP. Páginas da web só são buscadas quando você pede.
  • As suas chaves de API ficam no seu aparelho, no cofre do sistema operacional, pelo armazenamento seguro do Obsidian.
  • Conversas, o índice do Vault Q&A, skills e relatórios ficam salvos como arquivos no seu vault.
  • A lista completa do que o plugin envia, e pra quem, está nas Declarações do README.

04GitHub e o diretório do Obsidian

Se você abre uma issue, começa uma discussão ou instala o plugin pelo diretório da comunidade do Obsidian, esses serviços tratam os seus dados pelas próprias políticas (GitHub, Obsidian).

05Patrocínio

Se você patrocina o AXXA Agent pelo GitHub Sponsors, o GitHub processa o pagamento pela própria declaração de privacidade. A gente passa a ver o seu nome de usuário no GitHub e o patrocínio, e o seu e-mail só se você escolher compartilhar. Usamos isso só pra agradecer e pra guardar os registros que a lei exige (bases legais: LGPD, art. 7º, IX e II). O patrocínio não dá nada no plugin e nunca é obrigatório.

06Os seus direitos

Pela Lei Geral de Proteção de Dados (LGPD), você pode perguntar se a gente tem dados seus e pedir acesso, correção ou exclusão. Como nem este site nem o plugin mandam dados pessoais pra nós, normalmente não temos nenhum, fora os de patrocínio. Se você entrar em contato, a gente usa a sua mensagem só pra responder (base legal: LGPD, art. 7º, IX) e apaga quando a conversa não for mais necessária. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

07Mudanças

Se esta política mudar, a versão nova aparece nesta página com a data nova. Se uma opção paga for criada no futuro, esta página será atualizada antes do lançamento, explicando o que o provedor de pagamento trata.

08Contato

E-mail: contato@axxalab.com.br. Você também pode escrever no GitHub Discussions, ou reportar um problema de segurança em particular pelo aviso privado do GitHub.
