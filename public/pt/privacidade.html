Política de privacidade

Atualizada em 2 de outubro de 2026

Esta política vale para este site e para o plugin AXXA Agent para Obsidian, os dois feitos pela AXXA Lab™. Em resumo: a gente não coleta os seus dados. O site não usa cookies nem analytics, e o plugin não tem telemetria.

Quem é o responsável

A AXXA Lab™, desenvolvedora do AXXA Agent, no Brasil. Para qualquer dúvida de privacidade, escreva pra contato@axxalab.com.br.

Este site

  • É um site estático. Não tem formulário, conta, cookie, analytics nem anúncio.
  • Tudo o que ele mostra (texto, estilo, imagens) vem deste domínio. Ele não carrega fonte, script nem rastreador de terceiros.
  • O site fica hospedado na Cloudflare. Como qualquer servidor web, a Cloudflare recebe os dados técnicos que o navegador manda pra carregar uma página (como o seu endereço IP e o tipo de navegador) e podem guardar isso em registros, por segurança e pra entregar o site. Esse tratamento segue a Política de Privacidade da Cloudflare. A gente não usa esses registros.

O plugin AXXA Agent

  • O plugin roda no seu aparelho, dentro do Obsidian. Não tem telemetria e não manda nada pra nós.
  • Quando você usa um provedor de IA (OpenAI, Anthropic, Google Gemini, OpenRouter, NVIDIA NIM, ElevenLabs ou o seu servidor Ollama), o seu aparelho manda as suas mensagens, os anexos e os trechos de notas que o plugin usa direto pra esse provedor, com a chave de API que você configurou. Cada provedor trata esses dados pelos próprios termos e política de privacidade.
  • As suas chaves de API ficam no seu aparelho, no cofre do sistema operacional, pelo armazenamento seguro do Obsidian.
  • Conversas, o índice do Vault Q&A, skills e relatórios ficam salvos como arquivos no seu vault.
  • A lista completa do que o plugin envia, e pra quem, está nas Declarações do README.

GitHub e o diretório do Obsidian

Se você abre uma issue, começa uma discussão ou instala o plugin pelo diretório da comunidade do Obsidian, esses serviços tratam os seus dados pelas próprias políticas (GitHub, Obsidian).

Os seus direitos

Pela Lei Geral de Proteção de Dados (LGPD), você pode perguntar se a gente tem dados seus e pedir acesso, correção ou exclusão. Como nem este site nem o plugin mandam dados pessoais pra nós, normalmente não temos nenhum. Se você entrar em contato, a gente usa a sua mensagem só pra responder.

Mudanças

Se esta política mudar, a versão nova aparece nesta página com a data nova. Se uma opção paga for criada no futuro, esta página será atualizada antes do lançamento, explicando o que o provedor de pagamento trata.

Contato

E-mail: contato@axxalab.com.br. Você também pode escrever no GitHub Discussions, ou reportar um problema de segurança em particular pelo aviso privado do GitHub.
