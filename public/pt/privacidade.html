AXXA Agent · privacidade

Política de privacidade.

Esta política vale para este site e para o plugin AXXA Agent para Obsidian, os dois feitos pela AXXA Lab™. Em resumo: a gente não coleta os seus dados, a não ser o que você decide mandar pra gente por e-mail ou compartilhar quando patrocina o projeto. O site não usa cookies nem analytics, e o plugin não tem telemetria.

01 Quem é o responsável

A AXXA Lab™, desenvolvedora do AXXA Agent, com sede no Brasil, é a controladora dos dados deste site. Para qualquer dúvida de privacidade, escreva pra contato@axxalab.com.br. Esse endereço é o canal de privacidade; como agente de tratamento de pequeno porte, a AXXA Lab™ não indicou encarregado de dados (Resolução CD/ANPD nº 2/2022, art. 11).

02 Este site

  • É um site estático. Não tem formulário, conta, cookie, analytics nem anúncio.
  • Tudo o que ele mostra (texto, fontes, estilos, imagens e vídeo) vem deste domínio. Ele não carrega fonte, script nem rastreador de terceiros.
  • O site fica hospedado no GitHub Pages, e a Cloudflare responde às consultas de DNS do domínio. Como qualquer servidor web, o GitHub recebe os dados técnicos que o seu navegador manda pra carregar uma página (como o seu endereço IP e o tipo de navegador) e pode guardar isso em registros, por segurança e pra entregar o site. Esse tratamento segue a Declaração de Privacidade Geral do GitHub, e o DNS segue a Política de Privacidade da Cloudflare. A gente não usa esses registros. A base legal é o legítimo interesse em manter o site no ar e seguro (LGPD, art. 7º, IX).

03 O plugin AXXA Agent

  • O plugin roda no seu aparelho, dentro do Obsidian. Não tem telemetria e não manda nada pra gente.
  • Quando você usa um provedor de IA (OpenAI, Anthropic, Google Gemini, OpenRouter, NVIDIA NIM, ElevenLabs ou o seu próprio servidor Ollama), o seu aparelho manda direto pra ele o que aquele recurso precisa, com a chave de API que você configurou. O provedor do chat recebe as suas mensagens, os seus anexos e os trechos de notas usados como contexto; no modo Agent, ele também recebe as notas que o agente lê e os resultados das ações dele. Enquanto o índice do Vault Q&A é montado, o provedor de embedding recebe o texto das suas notas e, se o modelo lê imagens, as imagens também; depois, recebe o texto de cada busca no vault. O ditado manda a sua gravação pra OpenAI, e a leitura em voz alta manda o texto da resposta pra OpenAI ou pra ElevenLabs. Cada provedor trata esses dados conforme os próprios termos e a própria política de privacidade. Com um modelo no Ollama, esse tráfego fica entre o seu aparelho e o seu próprio servidor.
  • Nas conversas de Vault Q&A e Agent, um interruptor por conversa nasce ligado: trechos das notas que combinam com a sua mensagem vão junto dela pro provedor do chat e continuam indo nas suas próximas mensagens daquela conversa, mesmo que você desligue o interruptor depois. No Chat ele nasce desligado.
  • O que vai com uma mensagem fica com ela. Nas suas próximas mensagens daquela conversa, o provedor do chat recebe de novo os mesmos trechos de notas e notas anexadas, os resultados anteriores do agente (os mais longos, cortados) e, enquanto a conversa estiver aberta, as imagens e PDFs das suas três últimas mensagens que têm esse tipo de anexo. Quando uma conversa longa chega perto do limite do modelo, o mesmo provedor recebe um pedido pra resumir o começo dela, e esse resumo passa a ir no lugar das mensagens mais antigas.
  • Com a OpenAI e o OpenRouter, cada pedido de resposta também leva um identificador que o plugin cria pra conversa, sem nada do conteúdo dela, pra que o provedor reaproveite o cache de prompt. Nos modelos Claude (da Anthropic ou pelo OpenRouter), o plugin pede que o provedor guarde os pedidos da conversa nesse cache por alguns minutos.
  • O Acesso à web do agente vem ligado por padrão (Configurações › AXXA Agent › Agent). Com ele, o agente pode abrir páginas públicas da web e, com a sua própria chave da Tavily, pesquisar na web pela API de busca da Tavily. A Tavily recebe a busca que o agente escreveu, e uma página que ele abre recebe um pedido simples pra aquele endereço. Nos níveis de permissão Ask e Vault, cada busca e cada endereço espera o seu OK, a menos que você já tenha escolhido Aprovar tudo num pedido à web naquela mesma rodada; no YOLO, rodam sem perguntar.
  • As respostas aparecem como Markdown, então uma imagem com link dentro de uma resposta é carregada de onde o link aponta, e o servidor de lá vê o seu endereço IP. Uma página que você anexa com + › Link só é buscada quando você pede.
  • As suas chaves de API ficam no seu aparelho, no armazenamento de segredos do Obsidian, e não no arquivo de configurações do plugin. No computador, o Obsidian criptografa as chaves com a proteção do seu sistema operacional (o Keychain, a proteção de dados do Windows ou o chaveiro do Linux) quando ela está disponível; no celular, elas vão pro armazenamento seguro do sistema.
  • Conversas, o índice do Vault Q&A, skills e relatórios ficam salvos como arquivos no seu vault. O arquivo de uma conversa também guarda o que foi junto com cada mensagem sua (trechos de notas e o texto das notas, textos colados e páginas que você anexou), os resultados do agente (os mais longos, cortados) e o resumo de uma conversa longa, codificados, mas sem criptografia. Imagens e PDFs não ficam nele.
  • Mais detalhes sobre o que o plugin envia, e pra quem, estão na seção Declarações do README dele.

04 GitHub e o diretório do Obsidian

Se você abrir uma issue, começar uma discussão ou instalar o plugin pelo diretório da comunidade do Obsidian, esses serviços tratam os seus dados conforme as próprias políticas (GitHub, Obsidian).

05 Patrocínio

Se você patrocinar o AXXA Agent pelo GitHub Sponsors, o GitHub processa o pagamento conforme a própria declaração de privacidade. A gente passa a ver o seu nome de usuário no GitHub e o patrocínio, e o seu e-mail só se você escolher compartilhar com a gente. Usamos isso só pra agradecer e pra guardar os registros que a lei exige (bases legais: LGPD, art. 7º, IX e II). Patrocinar não libera nada no plugin e nunca é obrigatório.

06 Os seus direitos

Pela Lei Geral de Proteção de Dados (LGPD) e por leis parecidas, você pode perguntar se a gente tem dados seus e pedir acesso, correção ou exclusão. Como nem este site nem o plugin mandam dados pessoais pra gente, normalmente não temos nenhum, fora os de patrocínio. Se você entrar em contato, a gente usa a sua mensagem só pra responder (base legal: LGPD, art. 7º, IX) e apaga quando a conversa não for mais necessária. Você também pode registrar uma reclamação na Autoridade Nacional de Proteção de Dados (ANPD).

07 Mudanças

Se esta política mudar, a versão nova vai aparecer nesta página com uma data nova. Se uma opção paga for criada no futuro, esta página vai ser atualizada antes do lançamento, pra explicar o que o provedor de pagamento trata.

08 Contato

Mande um e-mail pra contato@axxalab.com.br. Você também pode escrever no GitHub Discussions ou avisar sobre um problema de segurança em particular, pelo relato privado de vulnerabilidades do GitHub.
