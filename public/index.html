01 answer and source

The answer, beside its source.

Ask in plain words. Vault Q&A answers from your notes and names the ones it used as links. Click one and the note opens; Ctrl/Cmd-click opens it in a new tab. On the phone, the panel steps aside so you can read it.

keyword
Names, dates, rare terms.
vector
Meaning, so other wording still matches.
links
A note linked from another match moves up.

Vector search uses an index stored in your vault, built with a cloud embedding model or one on your own Ollama. By default, re-indexing only re-embeds notes that changed. Without an index, search uses keywords.

02 agent

It asks first. You can undo after.

Describe a change in plain words. The agent searches, reads, creates, edits, moves and deletes notes, and creates folders, all inside your vault. By default, every change waits for your OK and shows the tool and the exact path first.

ask
Askdefault

Every change waits for your OK.

vault
Vault

Creating, editing and moving run on their own. Deletes ask.

yolo
YOLO

Everything runs on its own, deletes included, to the trash your Deleted files setting picks. If Obsidian is set to delete files permanently, deletes still ask.

  • Undo, per turn or per action.

    Undo under the answer reverts the whole turn, and each action has its own. It covers edits, new notes, moves, deletes and new folders while Obsidian stays open (a deleted file over 20 MB keeps no copy, so it only goes to your trash). If you edited the note by hand since, Undo stops and asks.

  • Obsidian does the moving.

    Moves go through Obsidian, so links update by your own link setting, and Undo writes them back. Deletes follow your Deleted files setting.

  • The web, on your terms.

    With Web access, on by default in Settings › AXXA Agent › Agent, the agent can open public pages, and search the web with your own Tavily key. In Ask and Vault, each search and address waits for your OK, unless you chose Approve all earlier in that turn.

03 in your notes

Right where you write.

Select text and right-click to rewrite it, fix its grammar and spelling, translate it, or send it to the chat. Right-click a note to ask about it or summarize it. Rewrites go straight into the note, and Ctrl/Cmd+Z takes them back.

7 commands
  • Ask about this note
  • Summarize this note
  • Send selection to chat
  • Rewrite selection
  • Fix grammar and spelling in selection
  • Translate selection…
  • Continue writing

On the phone, add them to the editor toolbar. In the chat, + › This note attaches the note you have open.

06 models and cost

Six providers. Your key. Your budget.

Use OpenAI, Anthropic, Google Gemini, OpenRouter or NVIDIA NIM with your own API key, or a model on your own Ollama server with no key. You pay the provider directly; AXXA Lab™ takes no cut.

Also: dictation (OpenAI) and read aloud (OpenAI, or your ElevenLabs voices), skills as slash commands, projects with their own instructions and source notes, and attachments: notes, images, a page by link, and PDFs with OpenAI, Anthropic or OpenRouter.

07 privacy

Your key. Your vault. Your machine.

  1. i

    Your key.

    Bring a key from OpenAI, Anthropic, Google Gemini, OpenRouter or NVIDIA NIM, or run Ollama with none. Keys are kept in Obsidian’s secret storage, not in the plugin’s settings file, so they don’t travel through Sync or backups.

  2. ii

    Your vault.

    Chats are saved as Markdown files in your vault, in a hidden folder by default. Skills, usage reports and exported chats are ordinary notes, and the search index lives in your vault too.

  3. iii

    Your machine.

    With Ollama, Chat, Vault Q&A and the agent can all run on your own computer. The agent needs a model that supports tools.

Your notes go only to the services you set up, never to AXXA Lab™. No telemetry, no AXXA account. Every request the plugin can make is listed in the Disclosures; this site’s own practices are in the privacy policy.

08 setup

Three steps to a first answer.

  1. Add it.

    Open the AXXA Agent page and choose Add to Obsidian, or search for AXXA Agent in Settings › Community plugins › Browse.

  2. Enable it.

    Install and enable it, then open Settings › AXXA Agent › Providers.

  3. Connect a provider.

    Add a key for one provider, or your Ollama address (usually http://localhost:11434). Then open the panel from the ribbon, or run AXXA Agent: Open panel.

11 faq

Common questions.

Is it free?

Yes. Every feature in the plugin today is free, with no tier, no account and no license key, and it stays that way. If paid options appear later, they will be new things built on top, never a lock on something that already worked. You pay your AI provider directly; the plugin takes no cut.

Which models can I use for free?

Each provider has its own rule. The model list in Settings tags each free model, with its limit where there is one, and the Usage screen shows what’s left today. Gemini: the Flash models, 2.5 Pro, embeddings and Gemma, on a project without billing, where Google may use what you send to improve its products; image generation is always paid. OpenRouter: models priced at zero, 20 requests a minute and 50 a day per account, or 1,000 a day once the account has bought $10 in credits. NVIDIA NIM: only the models NVIDIA marks Free Endpoint, for development and testing, up to 40 requests a minute. OpenAI: free daily tokens for eligible organizations that share their API data with OpenAI, on an account with a positive balance. Ollama: any local model. Checked October 2026.

Does it work on my phone?

Yes. Chat, Vault Q&A and the agent with its confirmations all run in Obsidian’s mobile app. Cloud providers work anywhere; Ollama runs on a computer, so a phone needs an Ollama server it can reach.

Can it run without the cloud?

Yes, with Ollama. Chat, Vault Q&A and the agent can all run on your own machine. The agent needs a model that supports tools.

What leaves my device?

Only what goes to the services you set up: your chat provider; your embedding provider, if it’s a different one; OpenAI for dictation; OpenAI or ElevenLabs for read aloud; Tavily and the pages the agent opens, when web access is used; and pages you attach by link. An image link inside an answer loads from wherever it points, and that server sees your IP address. Nothing goes to AXXA Lab™. The Disclosures list every request.

What if the agent gets it wrong?

Undo under the answer reverts the whole turn, and each action has its own, while Obsidian stays open. If you edited the note by hand since, Undo stops and asks first.

Is it in Portuguese?

Yes, the whole interface is available in Brazilian Portuguese. New installs start on Same as Obsidian, which follows Obsidian’s language. If you used AXXA before 0.9.23, choose Same as Obsidian or Português (Brasil) in Settings › AXXA Agent › Chat › Language.

Can I keep other AI plugins installed?

Yes. AXXA Agent runs in its own panel, its styles are scoped to that panel, and it doesn’t depend on or replace other plugins.

Where do I report a bug or ask a question?

Bugs go to the bug report form, questions and ideas to Discussions.
