02Modes

Three modes in one panel

Chat

Talk to the model you pick, from any of the six providers. Recent chats wait on the home screen.

Vault Q&A

Ask about your notes. The search runs three ways at once, and the answer cites the notes it used as links you can open.

keyword
Names, dates, rare terms.
vector
Meaning, so synonyms match.
links
A note linked from another match moves up.

Agent

Creates, edits, moves and deletes notes through a small set of tools. Every change waits for your OK. Moves and deletes go through Obsidian itself, so your link and trash settings apply.

On the phone

  • Keyboard-aware

    The composer stays above the on-screen keyboard.

  • Fullscreen if you want it

    An optional mode gives the panel the whole screen.

  • Nothing left out

    All three modes, confirmations included, run in Obsidian’s mobile app.

06Setup

Get started in a minute

Requires Obsidian 1.11.4 or newer, on desktop or mobile.

  1. Add it

    Open the AXXA Agent page and choose Add to Obsidian, or search for AXXA Agent in Settings › Community plugins › Browse.

  2. Enable it

    Install and enable it, then open Settings › AXXA Agent › Providers.

  3. Connect a provider

    Add a key for one provider, or the address of your Ollama server (usually http://localhost:11434), and start a chat.

Free ways to start

You only need one provider.

Google Gemini
A free tier on a project without billing. Image generation is paid.
OpenRouter
Free models, 50 requests a day per key (1,000 after $10 in credits).
NVIDIA NIM

Ollama
Runs models on your own computer, with no key and no account.

07Privacy

Your notes stay yours

What leaves your device goes to one place: the AI provider you picked.

  • Keys on your device

    Stored in your OS keychain through Obsidian’s secret storage, never in the plugin’s settings file, so they don’t travel through Sync or backups.

  • Only the provider you chose

    Your notes leave the device only as part of a conversation or the Vault Q&A index. The index itself stays in your vault.

  • Offline with Ollama

    Chat and the agent run fully on your machine with a local model. Vault Q&A then searches by keyword, because the embedding models are cloud services.

Every network request the plugin makes is listed in the Disclosures. This site’s own practices are in the privacy policy.

08FAQ

Common questions

Is it free?

Yes. Every feature in the plugin today is free, with no tier, no account and no license key, and it stays that way. If paid options appear later, they will be new things built on top, never a lock on something that already worked. You pay your AI provider directly; the plugin takes no cut.

Which models can I use for free?

Each provider has its own rule, and the model list in Settings shows the limit next to each free model. Gemini: the Flash models, 2.5 Pro, embeddings and Gemma, on a project without billing, where Google may use what you send to improve its products; image generation is always paid. OpenRouter: models priced at zero, 20 requests a minute and 50 a day per key, or 1,000 a day once the account has bought $10 in credits. NVIDIA NIM: only the models NVIDIA marks Free Endpoint, for development and testing, up to 40 requests a minute. Ollama: any local model.

Does the agent work on mobile?

Yes. Chat, Vault Q&A and the agent with its confirmations all run in the Obsidian mobile app. Cloud providers work anywhere; Ollama runs on a computer, so using it from a phone needs an Ollama server the phone can reach.

What leaves my device?

Only what goes to the provider you chose: your messages, what you attach, and the note excerpts that Vault Q&A and the agent use. Nothing goes to AXXA Lab.

Can I keep other AI plugins installed?

Yes. AXXA Agent runs in its own panel, its styles are scoped to that panel, and it doesn’t depend on or replace other plugins.

Where do I report a bug or ask a question?

Bugs go to the bug report form, questions and ideas to Discussions.
